# Monaco Editor Web-based IDE

This project implements a web-based code editor similar to Visual Studio Code using Monaco Editor. It provides features like syntax highlighting, code completion, and Java Language Server Protocol (LSP) integration.

## Features

- Syntax highlighting for multiple languages
- Code auto-completion / IntelliSense
- Auto-indentation
- Multi-language support switching
- Java LSP integration
- Dark/light theme toggle
- Line numbers and code folding

## Setup

1. Open `index.html` in a web browser to use the editor.
2. The editor supports Java and other common programming languages.

## Implementation Details

- Uses Monaco Editor (the same editor used in VS Code)
- Integrates with Java Language Server for enhanced Java development experience
